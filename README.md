# 진료정보 분석 (브라우저 버전)

심평원 '내 진료정보 열람'에서 받은 개인진료정보내역 PDF(기본진료정보 · 세부진료정보 · 처방조제정보)를
브라우저 안에서 표로 읽어 주상병 · 약품 · 수술 내역을 정리합니다.

- PDF는 서버로 전송되지 않고 사용자의 브라우저에서만 처리됩니다.
- 결과는 화면 표, 정리 엑셀(9개 시트), PDF별 CSV로 내려받을 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 |
| `app.js` | 파일 넣기 · 결과 표 · 내려받기 |
| `core.js` | PDF 표 읽기 · 정리 · 요약 · CSV/엑셀 생성 |
| `lib/pdf.min.js`, `lib/pdf.worker.min.js` | pdf.js 3.11.174 (Apache-2.0) |
| `lib/exceljs.min.js` | ExcelJS 4.4.0 (MIT) |

## 표기 기준

- 주상병명 요약: 외래 7일 이상 또는 입원 1일 이상
- 약품명 요약: 총투약일수 30일 이상 (병원 처방 기준)
- 수술 내역: 치과 수술 제외
